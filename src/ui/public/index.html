开始配置

选择 ServerChan、Telegram Bot 或 QQ Bot，并在下一步填写凭据和固定目标。

凭据只会发送到本机回环服务，并保存在独立的私密文件中；主配置、预览、日志和 API 响应不会包含完整值。

渠道

不知道 Chat ID？协助发现
  1. 私聊：打开这个 Token 对应的 Bot，点击 Start 并发送 /start。
  2. 群聊：把 Bot 加入目标群，发送 /start@Bot用户名 或 @Bot。
  3. 回到这里点击“查找候选 Chat ID”。发现操作不发送消息，也不读取消息正文。
尚未查找

必须是该机器人的不透明 OpenID，纯数字 QQ 号/群号无效。

不知道 OpenID？查看获取路径
  1. 先在 QQ 开放平台为机器人启用群聊或单聊消息事件，并连接 WebSocket Gateway 或配置 Webhook。
  2. 让目标用户私聊机器人，或在目标群里 @机器人，触发一条入站事件。
  3. 从该事件提取对应的用户 OpenID 或群 OpenID；OpenID 与 Bot AppID 绑定，不能跨机器人复用。
  4. 没有事件接收器时，回到 Agent 对话说“协助获取 QQ OpenID”，由 Agent 帮你检查现有网关或搭建临时接收流程。
